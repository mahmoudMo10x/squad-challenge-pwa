# تحدي التشكيلة — Online MVP v0.3

نسخة PWA أونلاين عمودية مبنية من Game Bible الرسمية، مع وضع كمبيوتر احتياطي للاختبار.

## الموجود حاليًا

- بحث تجريبي عن منافس.
- Draft من 14 دورًا بالترتيب `GK, DEF, DEF, MID, MID, FWD, FWD`.
- أربعة صناديق؛ الأول قبول/رفض والثاني إجباري.
- Matchmaking حقيقي يجمع لاعبين داخل غرفة سلطوية.
- 500 لاعب خيالي بالتوزيع الرسمي 60 GK / 145 DEF / 155 MID / 140 FWD.
- بطاقة الكشف تعمل أثناء الـDraft دون استهلاك محاولة.
- الحماية تمنع السرقة، والسرقة والتبديل يعملان بعد الـDraft.
- الخصم الآلي يقرر استخدام بطاقة فعالة واحدة وفق حالة الفريقين.
- مؤقتات خادم، منع أفعال قديمة أو مكررة، وإخفاء محتويات الصناديق.
- Reconnect يعيد اللاعب إلى المقعد والحالة نفسها خلال مهلة السماح.
- تقرير توازن من 55,000 مباراة داخل `reports/balance-baseline.json`.
- أربعة تشكيلات وخمسة تكتيكات.
- محرك Seeded لمباراة 60 ثانية/دقيقة مع ترجيح عند التعادل.
- نتيجة، MVP وسبب مبسط.
- واجهة عربية RTL ومراعاة reduced motion.

## مؤجل للمرحلة التالية

- حسابات مستخدمين موثقة وقاعدة بيانات دائمة.
- Redis وتشغيل عدة نسخ خادم للتوسع.
- مؤثرات الحركة والصوت النهائية للبطاقات.
- صور وأصول نهائية وقاعدة 500 لاعب.
- معايرة Monte Carlo الشاملة.
